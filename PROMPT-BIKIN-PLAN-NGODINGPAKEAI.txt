Saya ingin membuat ulang aplikasi "Sahabat Mahasiswa", yaitu portal all-in-one kebutuhan harian mahasiswa Indonesia berbasis Next.js App Router, Tailwind CSS, TypeScript, dan Supabase (PostgreSQL + Auth).

Aplikasi ini memiliki 5 modul utama dan 1 modul autentikasi/profil:
1. Cari Kosan Mahasiswa:
   - Pencarian kos berbasis lokasi GPS & jarak akurat ke kampus (fungsi PostgreSQL Haversine).
   - Filter harga maksimal per bulan, tipe kos (Putra, Putri, Campur), fasilitas (WiFi, AC, Kamar Mandi Dalam).
   - Urutkan kosan termurah atau terdekat dari posisi mahasiswa.
   - Hubungi pemilik kos langsung via WhatsApp.

2. Voucher & Diskon Makanan:
   - Aggregator promo kuliner hemat mahasiswa dari TikTok GO Dining, GrabFood, GoFood, dan ShopeeFood.
   - Filter chip berdasarkan platform kuliner dan diskon terbesar.
   - Fitur satu klik salin kode promo & link klaim langsung ke aplikasi terkait.

3. Dompet Mahasiswa (Smart Daily Budget):
   - Smart Daily Limit: otomatis menghitung sisa jatah belanja harian aman dari sisa saldo dibagi sisa hari bulan berjalan.
   - Visual progress bar anggaran bulanan (persentase terpakai).
   - Catat transaksi cepat (pemasukan/pengeluaran, kategori khusus mahasiswa, nominal, catatan).
   - Riwayat transaksi real-time dan fitur ekspor/salin ringkasan keuangan.

4. Jadwal & Deadline Tugas:
   - Pengingat tugas kuliah cerdas dengan prioritas otomatis (nama tugas, tanggal deadline, bobot kesulitan 1-3).
   - Checklist tugas selesai dengan penyimpanan status di Supabase.

5. Lowongan Kerja Part-Time & Magang:
   - Kurasi lowongan ramah jadwal kuliah (Barista, Tutor, Event Staff, Freelance, Admin).
   - Filter batas jam kerja per minggu (maks 10, 20, 40 jam) dan tipe kerja.
   - Detail persyaratan, estimasi upah, dan tombol lamar cepat ke HRD.

6. Autentikasi & Profil Pengguna:
   - Supabase Auth: Email/Password & Google OAuth.
   - Guest lock gate: pengguna belum login tetap bisa melihat katalog umum, tetapi fitur interaktif/pribadi terkunci dengan prompt login elegan.
   - Halaman profil mahasiswa (nama, kampus, jurusan, no hp) serta toggle tema Gelap/Terang.

Tech stack yang diinginkan:
- Next.js (App Router), TypeScript, Tailwind CSS, Lucide React
- Backend: Supabase (Auth, PostgreSQL DB, RLS)
- UI: Mobile-first dengan bottom navigation dock dan card glassmorphism modern (Plus Jakarta Sans).

Tolong buatkan PRD lengkap, spesifikasi fitur, skema database Supabase, dan task list implementasi bertahap untuk AI coding agent.
